# Preset examples

PERCUSYN presets in the portable JSON format (`"format": "percusyn-preset"`, schema 2). They load in the plug-in (••• → Import preset JSON) and in the browser mockup.

- `01`–`06` are embedded in the plug-in as its factory kits.
- `00-current-design-snapshot.json` is the full-kit state from the final design session of the browser mockup.
